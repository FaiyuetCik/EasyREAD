# Faiyuet Morgan 使用说明

2026-10-08，Sticky 软件验证版。固件已编译，尚未烧录或在设备上验证。

## microSD 准备

使用 FAT32 卡，把项目 `sd-card` 中的 `Fonts` 和 `Books` 文件夹复制到卡根目录。保留两个 TTF 字体和 LICENSE.txt。无需 Wi-Fi 或账户。

```
/
├── Fonts/
│   ├── NotoSansSC-VF.ttf
│   ├── NotoSansTC-VF.ttf
│   └── LICENSE.txt
└── Books/
    └── Faiyuet-Morgan-test.epub
```

自己的无 DRM EPUB 可以放在根目录、Books 或子目录。启动时递归扫描，最多 1000 本、12 层目录；以文件名排序。自动生成 `/FM` 分页缓存。缓存可以重新生成，阅读位置和设置保存在设备 NVS。

## 书架和阅读

- 书架：实体上/下键选择，AI/确认键打开；触摸书名也可打开。上下滑动可滚动长列表。
- 阅读：实体上键上一页，下键下一页；触摸页面左侧上一页、右侧下一页，中间打开菜单。左右滑动也可翻页。
- 阅读菜单：继续、目录、排版设置、蓝牙翻页器、书架、休眠、封面。
- 目录：点选章节；有章内锚点的目录条目跳转到对应文字所在页面。
- 启动后自动恢复上次书籍。每次翻页保存章节和文字偏移；字号、行距或边距改变后重新分页，恢复到包含该偏移的页面。
- 阅读页底部显示章节、章内页码和章内文字进度。尚未把每章全部分页，故不显示全书总页数。
- 每八次普通刷新做一次全刷新，减少残影；菜单切换、章节切换使用全刷新。

## 图片和封面

支持 PNG 和 JPEG 图片按比例排版，黑白抖动显示。点图片进入查看器；也可以从菜单单独打开 EPUB 标记的封面。

- 点查看器顶部或按确认键：1×、2×、4×循环放大。
- 滑动图片移动视区；左右区域或方向键水平移动，上/下区域或方向键垂直移动。
- 点屏幕底部返回阅读。

不支持 SVG、GIF、WebP、交错 PNG。此类图片提示不支持，其余文本仍可阅读。EPUB 复杂表格、数学排版及全部 CSS 效果不作为本版完整支持范围。

## 排版和设备设置

书架顶部可打开设置，阅读菜单也可进入。点某一设置行的左半边减少、右半边增加；字体地域和自动休眠选项循环切换。

- 字号：18–42 像素。
- 行距：100–180%。
- 边距：12–48 像素。
- 字体：简体或繁体地域字形优先，另一份字体补字；包含英文，并接入粗体和斜体。
- 自动休眠：关闭、5、10、30 分钟。默认 10 分钟。
- 应用并返回：阅读中重新分页，保留文字位置。
- 蓝牙、重新扫描、手动休眠也可以在设置中进入。

两份固定字体均从 SD 卡流式读取，无需整体载入内存。嵌入的英文字体用于缺卡、缺字体等错误提示。

## Page Turner 蓝牙翻页器

打开蓝牙页面，选择“搜索翻页器”，让翻页器进入配对状态，再选对应设备。已配对设备会记录在 NVS，并由 SDK 自动重连。

- Left / PageUp → 上一页；Right / PageDown → 下一页。
- Up / Down → 上一页/下一页，或列表选择。
- Enter → 确认；Escape → 返回。
- 可关闭蓝牙、断开连接或清除配对。

只支持 BLE HID；具体这只 Page Turner 的发现、配对和按键报告仍待真机验证。桌面模拟测试不代表已经连接过实物。

## 休眠、唤醒与故障提示

长按 AI/电源键或菜单选择休眠。固件保存位置，关闭 BLE、显示休眠提示、关闭外设电源并进入深度休眠。按 Sticky AI/电源键唤醒后重启并恢复阅读。

缺卡、缺字体、无法读取书籍、DRM、分页缓存写入失败等会显示提示。插入 SD 后重启；字体缺失时先复制 Fonts。

## 烧录

建议从源码用 PlatformIO 完整上传流程，保持 bootloader、分区表与应用匹配。在项目根目录运行：

```powershell
$env:PLATFORMIO_CORE_DIR = 'D:\fm-pio-core'
& '.\firmware\.venv\Scripts\python.exe' -m platformio run -d '.\firmware' -e sticky -t upload --upload-port COM实际端口
```

固件包中 `faiyuet-morgan-sticky-full.bin` 为从地址 0x0 烧录的完整镜像；`faiyuet-morgan-sticky-app.bin` 仅为从 0x10000 烧录的应用，不能用它替代完整镜像。烧录会替换设备上的现有固件，本次开发没有执行烧录。

## 真机验收顺序

1. 首屏方向、四角触控、实体键；如方向相反，调整 FM_SPLASH_ROTATE_CW 后重新构建。
2. SD 挂载、递归扫描、共享 SPI 连续刷新和读卡。
3. 测试 EPUB 和真实简繁中文、英文 EPUB；目录、跨章翻页、图片与放大。
4. 更改字号、退出书籍、重启后验证同一阅读位置。
5. Page Turner 配对、左右键、重连和关闭蓝牙。
6. 手动/自动休眠、AI 键唤醒、外设断电和实际休眠电流。
7. 长时间翻页、不同卡、图片大书、稳定性及续航。

这些硬件验收项目均尚未完成。

## 已确定的产品要求

- 目标硬件：Seeed Studio reTerminal Sticky；默认且仅支持竖屏。
- 文件：离线、microSD 复制书籍、无 DRM 的 EPUB；不做 Wi-Fi 传书。
- 文本：简体中文、繁体中文、英文、中英混排。
- 图片：封面、图表、插画；按比例显示，图表放大查看列为目标功能。
- 操作：触控、Sticky 实体键、现有 Page Turner 蓝牙翻页器。翻页器左/右键对应上一页/下一页；Sticky 实体 AI/电源键唤醒。
- 阅读：书架、目录、进度、断点续读、基本排版设置。

## 技术调查

- 已阅读 Seeed Sticky 硬件与开发文档。Sticky 的显示屏与 microSD 共享 SPI，总线访问需要协调。
- 已核对 FreeInk SDK 与 freeink-reader。FreeInk SDK 提供 Sticky 板级配置、EPUB 引擎和 BLE HID 主机，可作为自有固件的依赖；不直接把别人的阅读固件当作我们的产品。
- FreeInk SDK 文档仍提示 Sticky 的方向与 SD 共享总线行为有待硬件验证，需以本机实测确认。
- 已在 firmware/.venv 安装 PlatformIO 6.2.0；pioarduino 与编译缓存位于 D 盘短路径，以避免 Windows 路径过长。
- FreeInk SDK 已下载在 firmware/freeink-sdk；固定检出的提交为 a1cf5b4be3e5259f856fe0497129e360e4e1346d，尚未修改 SDK。

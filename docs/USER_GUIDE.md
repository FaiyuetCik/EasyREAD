# EasyREAD 使用说明

2026-10-10，EasyREAD Sticky 开发版。当前源码已编译并烧录，SD、中文正文及翻页已有硬件验证；切章偶发启动页仍待定位，BLE 和睡眠唤醒尚未完整硬件验收。

## microSD 准备

使用 FAT32 卡，把项目 `sd-card` 中的 `Fonts` 和 `Books` 文件夹复制到卡根目录。保留两个 TTF 字体和 LICENSE.txt。无需 Wi-Fi 或账户。

```
/
├── Fonts/
│   ├── NotoSansSC-VF.ttf
│   ├── NotoSansTC-VF.ttf
│   └── LICENSE.txt
└── Books/
    └── Faiyuet-Morgan-test.epub
```

自己的无 DRM EPUB 可以放在根目录、Books 或子目录。启动时递归扫描，最多 1000 本、12 层目录；以文件名排序。自动生成 `/FM` 分页缓存。缓存可以重新生成，阅读位置和设置保存在设备 NVS。

### 新增格式（2026-10-10.1 开发预览）

TXT、XTC、XTCH 和 BMP 同样放在 `Books` 或子目录，重启后出现在书架；扩展名不区分大小写。

- TXT：支持 UTF-8、GBK 和带 BOM 的 UTF-16 LE/BE。无 BOM 时优先检测 UTF-8，不符合时按 GBK 解码；不支持 GB18030 四字节编码。首次打开会在 `/FM` 生成 EPUB 阅读缓存，显示转换进度，可长按 AI 取消；原 TXT 不变。单文件上限 128 MiB，SD 卡需有足够缓存空间。
- TXT 继续使用现有阅读设置和断点续读。短行以“第…章/回/卷/节”、Chapter、Part 或常见序言标题开头时建立目录，最多 1000 项；排版后的页数在后台继续生成。
- XTC/XTCH：按图片页阅读，支持翻页、保存当前页以及文件自带的目录。灰度页转换为黑白抖动；当前支持未压缩 XTG/XTH 页。边长上限 8192 像素，实际解码大小还受可用 PSRAM 限制。
- BMP：支持未压缩 RGB 的 1/4/8/24/32 位、上下两种行顺序；单张图片作为一条书架项目。最大边长 8192 像素，不支持 RLE、bitfields 或嵌入 JPEG/PNG 的 BMP。
- 图片书和 BMP 的阅读菜单用“查看图片”代替“阅读设置”，从这里进入图片查看器，可放大、缩小和拖动，再通过图片菜单返回阅读。其文字已固定为像素，不能改字号或行距。
- 新增格式的正常打开、显示方向、目录与重启续读仍需用实际文件做设备验收，不能将编译成功当作文件兼容性已验证。新版 2026-10-10.1 包包含新增格式；旧 2026-10-10 ZIP 仅对应此前 EPUB 版本。

## 书架和阅读

- 书架：实体上/下键选择，AI/确认键打开；点书名选中，再点同一本书打开。上下滑动可滚动长列表。
- 阅读：实体上键上一页，下键下一页；触摸页面左侧上一页、右侧下一页，中间打开菜单。左右滑动也可翻页。
- 阅读菜单：返回阅读、目录、阅读设置、返回书架、更多。“更多”包含蓝牙翻页器、查看封面、休眠和返回阅读菜单。
- 所有菜单选项均为第一次点按选中（黑色条移动到该项），再次点按同一项执行；改点另一项时只切换选中，不要求快速双击，也可用上下键选择、短按 AI 确认；返回也是列表中的选项，并写明返回目标。屏幕底部仅显示操作提示，点击不会返回。长按 AI 休眠。
- 目录：点选章节；有章内锚点的目录条目跳转到对应文字所在页面。
- 启动后自动恢复上次书籍。每次翻页保存章节和文字偏移；字号、行距或边距改变后重新分页，恢复到包含该偏移的页面。
- 阅读页底部只显示章节和章内页码。先生成当前页，再继续分页；尚未完成时已生成页数后显示加号，不显示全书总页数。
- 每八次普通刷新做一次全刷新，减少残影；菜单切换、章节切换使用全刷新。

## 图片和封面

支持 PNG 和 JPEG 图片按比例排版，黑白抖动显示。阅读页面中间区域的图片可点开查看器，左右区域优先用于翻页；也可以从“更多”单独打开 EPUB 标记的封面。

- 点图片中间或短按 AI 打开图片操作菜单。点按放大、缩小、返回图片或返回阅读选中，再点同一项执行；也可用上下键选择，再短按 AI 确认。
- 滑动图片移动视区；左右区域或方向键水平移动，上/下区域或方向键垂直移动。
- 返回阅读：点图片中间打开菜单，点“返回阅读”选中，再点一次确认；也可使用按键选择并确认。

不支持 SVG、GIF、WebP、交错 PNG。此类图片提示不支持，其余文本仍可阅读。EPUB 复杂表格、数学排版及全部 CSS 效果不作为本版完整支持范围。

## 排版和设备设置

书架右上角“设置”或书架列表的“系统设置”管理语言、自动休眠和蓝牙开关；系统设置中选择“返回书架”退出。从书内阅读菜单进入“阅读设置”，排版按书保存，新书使用默认值。点按设置整行选中，再点同一项进入编辑页；编辑页也先点选、再点同一项执行；也可选中设置后短按 AI 进入编辑页，上下键选择操作，再短按 AI 确认；编辑页最后一项返回对应设置页。

- 字号：18–42 像素。
- 行距：100–180%。
- 边距：12–48 像素。
- 字体：简体或繁体地域字形优先，另一份字体补字；包含英文，并接入粗体和斜体。
- 自动休眠：关闭、5、10、30 分钟。默认 10 分钟。
- 保存并返回阅读：保存本书排版，重新分页并保留文字位置。
- 蓝牙和手动休眠位于阅读菜单的“更多”。新增书籍后重启以重新扫描。

两份固定字体均从 SD 卡流式读取，无需整体载入内存。字宽与字体扇区缓存在 PSRAM 中；嵌入的 FaiyuetUI 中文/ASCII 子集用于固定菜单及缺卡等提示。

## Page Turner 蓝牙翻页器

打开蓝牙页面，选择“搜索翻页器”，让翻页器进入配对状态，再选对应设备。已配对设备会记录在 NVS，并由 SDK 自动重连。

- Left / PageUp → 上一页；Right / PageDown → 下一页。
- Up / Down → 上一页/下一页，或列表选择。
- Enter → 确认；Escape → 返回。
- 可关闭蓝牙、断开连接或清除配对。

只支持 BLE HID；具体这只 Page Turner 的发现、配对和按键报告仍待真机验证。桌面模拟测试不代表已经连接过实物。

## 休眠、唤醒与故障提示

长按 AI/电源键或菜单选择休眠。固件保存位置，关闭 BLE、显示休眠提示、关闭外设电源并进入深度休眠。按 Sticky AI/电源键唤醒后重启并恢复阅读。

缺卡、缺字体、无法读取书籍、DRM、分页缓存写入失败等会显示提示。插入 SD 后重启；字体缺失时先复制 Fonts。

## 烧录

建议从源码用 PlatformIO 完整上传流程，保持 bootloader、分区表与应用匹配。在项目根目录运行：

```powershell
$env:PLATFORMIO_CORE_DIR = 'D:\fm-pio-core'
& '.\firmware\.venv\Scripts\python.exe' -m platformio run -d '.\firmware' -e sticky -t upload --upload-port COM实际端口
```

当前 EasyREAD 完整包中 `binaries/full.bin` 为从地址 `0x0` 烧录的完整镜像；`binaries/firmware.bin` 仅为从 `0x10000` 烧录的应用，不能用它替代完整镜像。烧录会替换设备上的现有固件；完整镜像覆盖 NVS，会重置设备内部阅读位置与设置。已有匹配分区配置时可用应用镜像升级以保留 NVS。2026-10-08 和 2026-10-09 包是历史版本；2026-10-10 应用已编译并烧录到开发设备。新发布包的对应源码、依赖、许可和重新链接说明见 `docs/SHARING.md`。

## 真机验收顺序

1. 首屏方向、四角触控、实体键；如方向相反，调整 FM_SPLASH_ROTATE_CW 后重新构建。
2. SD 挂载、递归扫描、共享 SPI 连续刷新和读卡。
3. 测试 EPUB 和真实简繁中文、英文 EPUB；目录、跨章翻页、图片与放大。
4. 更改字号、退出书籍、重启后验证同一阅读位置。
5. Page Turner 配对、左右键、重连和关闭蓝牙。
6. 手动/自动休眠、AI 键唤醒、外设断电和实际休眠电流。
7. 长时间翻页、不同卡、图片大书、稳定性及续航。

SD 挂载、书架、中文正文及基本翻页已有硬件检查。其余项目及切章稳定性仍需继续验收。

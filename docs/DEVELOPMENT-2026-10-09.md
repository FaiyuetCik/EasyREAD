# 2026-10-09 开发与验证记录

## 已保存并烧录的改动

- Sticky 共用 SPI 先以 SD 的完整引脚初始化，SD 使用 4 MHz；连续字体/EPUB 文件通过 SdFat 连续寻址优化。
- UART 日志使用板级串口；触摸保留实测翻页校准；阅读左右边缘优先翻页，避免封面图片占满触摸区导致进入图片模式。
- 改用 ChapterLayoutSession：先生成当前页，再分步构建后续页面，保留部分缓存、书签字符偏移、目录锚点及取消等待功能。
- PSRAM 字宽缓存 8192 项、字体扇区缓存 256 × 512 字节，分配失败时退回直接读取。
- IncrementalChapter 保留文件名与 LayoutParams 副本。SDK 会引用参数，因此不能把调用方局部参数交给跨函数继续执行的排版会话。
- Arduino loopTask 栈提高到 16 KB；文件指纹缓冲缩小为 512 字节，指纹算法保持不变。
- 去除装饰横线，以黑底白字表示选中项；统一中文菜单、明确设置 [-] / [+] 以及实体键编辑操作。
- 阅读菜单保留继续、目录、设置、书架、更多；蓝牙、封面、休眠进入“更多”。书架文件名隐藏 EPUB 后缀。
- ReaderGeometry 手绘像素与 SDK PageRenderer 的旋转统一，修正启动图相对文字倒置、线条/选中底色错位。
- 固定中文/ASCII UI 字体采用重命名的 OFL Noto Sans SC 静态子集 FaiyuetUI，235 字符、43,896 字节；原始许可仍在 sd-card/Fonts/LICENSE.txt。

## 复现分段排版回归

在 Linux / WSL，先按 firmware/README.md 恢复固定 SDK，再执行：

```sh
python3 firmware/tools/run_incremental_check.py
# 可选：提供自己拥有的无 DRM EPUB 路径，文件不会写入仓库。
python3 firmware/tools/run_incremental_check.py /path/to/book.epub
```

默认使用项目原创测试书；输出在忽略的 firmware/test-results/。上面的 778 页记录来自当日本地真实书籍，默认样书的页数不同。

# GBK mapping provenance

`firmware/src/GbkTable.h` was generated by enumerating two-byte sequences
through CPython 3.12.10's standard `gbk` decoder. The generated data is a
flattened byte-pair-to-Unicode table; the application uses an independently
written decoder and does not embed Python or its codec implementation.
